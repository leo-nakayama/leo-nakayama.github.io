# Chapter 2 — Defining High-Context and Low-Context Societies

The foundational distinction between high-context and low-context societies
shapes communication at every level—from interpersonal interaction to strategic diplomacy.

High-context societies (e.g., Japan, China, Korea):

- encode meaning implicitly  
- rely on shared norms, unspoken assumptions, and stable relational cues  
- treat ambiguity as a functional feature  

Low-context societies (e.g., U.S., U.K., Germany):

- expect explicit articulation  
- treat ambiguity as a strategic liability  
- assume directness and transparency as default  

When high-context and low-context actors interact in diplomacy, several structural distortions occur:

1. loss of implicit intention  
2. misinterpretation of domestic legal categories  
3. parallel but incompatible national narratives  
4. rapid media-driven escalation  

Japan’s communication system is particularly high-context,
making it vulnerable to misalignment in a global arena that depends on explicitness.
