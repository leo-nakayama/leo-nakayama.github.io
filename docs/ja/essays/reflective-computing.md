# Reflective Computing 概要

Reflective Computing（リフレクティブ・コンピューティング）とは、  
**自己省察そのものを計算的形式として扱う試み**です。

この考え方は、単に「AIが人間の思考を模倣する」ことを超え、  
**「人間が自らの思考過程を形式化して観察する」**という方向へ向かいます。

---

## 基本構造

Reflective Computing は、次の4つの哲学的層から構成されます。

1. **Material Cause（素材）** — データ、経験、観察対象  
2. **Formal Cause（形式）** — 記述構造、DSL、リズム  
3. **Efficient Cause（作用）** — 人間・AI・ツールの関与  
4. **Final Cause（目的）** — 自己理解・意味生成・倫理的指向

---

## 日本語的思考との親和性

日本文化には「型を通じて心を映す」伝統があります。  
茶道、能楽、俳句のように、**形式（Form）を通じて反省（Reflection）へ至る**という構造は、まさに Reflective Computing の理念と響き合います。

> 「かたちを超えて、こころを映す」  
> — これはアルゴリズム的思索の美学でもある。
