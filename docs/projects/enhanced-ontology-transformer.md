# Enhanced Ontology Transformer

## 1 Premises - what transformers are

Transformers are not just predictive machines - they are structured attention systems over symbolic sequences.

### 1.1 In case of DSL modules

The idea of ontolgy transformers is based on my experience of developing and using philosophical DSL modules on the FOWL system. The DSL user experience provided changes in my range of possible ways of thinking. For example, DSL modules provide structual attention system. The Observation Report by Aristotle Four Causes module tells structured attention layers of the given subject. The report and the user experience of the module result in changing the user's space of possible thought trajectories.
